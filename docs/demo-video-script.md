# DEMO VIDEO SCRIPT: DatePack

목표 길이: **60초**. 한 가지 workflow: **기억 한 줄을 AI로 다듬어 원문과 함께 저장하기**.
30~60초 템플릿의 Hook / DEMO / CTA / BEFORE YOU PUBLISH를 사용한다.

대본과 녹화 없는 [실제 UI 리허설](demo-rehearsal.md)은 2026-10-01 로컬 작업 결과다.
영상 촬영·자막 제작·영상 export·게시를 수행하지 않았다. 이번 데모의 AI 답안은
수제 fixture다. 외부 LLM을 실행하거나 실제 AI 대화·승인을 확인한 장면으로 표현하지 않는다.
화면의 문구와 버튼은 최신 로컬 구현 기준이며 공개 배포본과의 일치는 미확인이다.

## Hook (0–3s)

**Show on screen:** 저장된 ‘비를 피해 쉬었던 순간’ 기록에서 **원문 — 그대로 보존**과
**확인해 저장한 문장**을 함께 보여준다. 마지막 결과 화면을 첫 장면으로 가져오는 편집 계획이다.

**Caption / voiceover:** “문장은 다듬고, 기억은 그대로.”

## DEMO (3–50s)

**The one workflow:** 더보기의 이미 저장한 원문을 확인하고, AI 요청을 준비한 뒤,
반환 답안을 검토해 원문 옆에 저장한다. 일정 생성·경로 변경·지도·사진·공유를 곁들이지 않는다.

| 시간                           | 장면 / 실제 버튼                                                                                                                                                                                       | Caption / voiceover                                                                                                                                                    |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 3–12s · Step 1                 | 더보기 → 함께한 순간. 원문 ‘비가 와서 카페에 들어갔다. 따뜻한 커피를 마시며 쉬었다.’를 읽고 **AI로 문장 다듬기**를 누른다.                                                                             | “적어 둔 기억을, 읽기 편한 한 줄로.”                                                                                                                                   |
| 12–27s · Step 2                | **AI에 보낼 요청문 보기**를 열어 제목·원문만 보내는 범위를 확인한다. 닫고 **요청문 복사**. 외부 앱 장면 대신 준비된 예시를 **AI 답안 붙여넣기**에 입력한다. 긴 JSON 타이핑과 이동은 편집에서 생략한다. | “요청을 쓰는 AI에 보내고, 고른 문장의 결과를 여기 붙여넣어요.” **화면 자막: ‘AI 답안 예시 · 수제 fixture’**. 외부 AI 사용은 설명이며 이번 리허설의 실행 증거가 아니다. |
| 27–40s · Step 3                | **다듬은 문장 검토** → 저장 전 확인. 원문과 ‘비를 피해 카페에서 따뜻한 커피를 마시며 쉬었다.’를 비교하고 **원문과 함께 저장**.                                                                         | “사실이 그대로인지 확인한 뒤 저장해요.”                                                                                                                                |
| 40–50s · The “oh, nice” moment | 요청 입력부가 닫힌 기록 카드. **원문 — 그대로 보존**과 **확인해 저장한 문장**을 같은 화면에 둔다.                                                                                                      | “원문도, 내가 확인한 문장도 함께 남아요.”                                                                                                                              |

리허설 준비: 별도 T07 계획에서 위 제목·원문을 실제 UI로 먼저 저장했다. 날짜·시각·장소는
비워 둔다. 기록 시각을 방문 시각처럼 설명하지 않는다. 재촬영 시에도 새 데모 기록을 UI로
만들어 동일 원문을 저장하고 시작한다. 사용자 기록을 지우거나 기존 데이터를 reset하지 않는다.

이번 리허설은 외부 AI 대화 대신 현재 요청의 식별값을 유지한 수제 답안으로 앱 내부 왕복을
확인했다. 실제 LLM이 생성·승인 후 JSON과 가져오기 안내를 준다는 동작은 별도 live 검증이 필요하다.
‘원클릭 AI’, 자동 외부 앱 전환, 실시간 위치 추적, 검증된 이동시간을 주장하는 자막은 넣지 않는다.

## CTA (last 10s · 50–60s)

**The one action:** “DatePack에서 기억 한 줄을 남겨보세요.”

**URL or handle on screen:** `threelightstudio.github.io/datepack/`

URL 근거는 [README의 Try it](../README.md#try-it)이다. 공식 handle을 새로 만들지 않는다.
공개 URL에서 T07 로컬 변경을 검증하거나 배포하지 않았다. 제작 전에 공개 버전과 화면을
맞춰 확인해야 한다. CTA는 방문 한 가지이며 다운로드·팔로우·공유 요청을 추가하지 않는다.
