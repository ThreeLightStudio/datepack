# 외출 계획과 사진 기록 흐름

현재 기준: **0.4.0 · 파일 4.0 · 2026-10-02 (Asia/Seoul)**.
승인된 U01–U04 계획이 이전 3.0 설계보다 우선한다.
[AI 계약](ai-flow-contract.md), [수용 기준](ai-flow-acceptance.md),
[검증과 한계](release-readiness.md)를 함께 읽는다.
이 체크아웃은 배포하지 않았다. T05–T07 문서와 기존 evidence는 당시 실행 기록이다.

## 계획 없이도 시작한다

홈은 저장된 계획이 없어도 열린다. 사진 남기기, 계획 만들기, 다음 날짜 있는 계획,
최근 기록과 이어 할 AI 작업·사용자가 확인한 외출을 보여 준다. 날짜만으로 외출 시작,
방문이나 완료를 판정하지 않는다. 다른 문서에 저장된 요청도 현재 선택과 무관하게 찾는다.

기본 탐색은 홈 / 일정 / 기록이다. 선택한 계획 안에서는 지금과 전체 일정의 역할을
유지한다. 언어·파일·앱 정보는 상단 메뉴에 둔다. 별도 온보딩이나 동행자 입력을 요구하지 않는다.

## 사진으로 끝내고 필요할 때 보완한다

사진 선택 → 미리보기에서 추가·제외 → 저장 한 번 → 완료. 여러 사진을 한 기록으로
저장하며 제목·설명·일정 연결은 필수가 아니다. 기록과 사진이 영속 저장된 뒤 완료를
표시하고 설명 시트를 자동으로 열지 않는다. 글만 남기는 경로도 제공한다.

완료 후 선택적으로 설명, 과거 경험 날짜·시각, 장소, 방문 확인을 보완한다. 기록한 시각과
경험 시각은 다르다. 설명이 없는 사진도 정상 기록이다. 원문을 직접 수정하면 이전 AI
편집문은 지워지며, AI의 표현 정리는 원문과 별도 저장한다.

기록 목록은 모든 문서의 기록을 모아 사진과 내용 중심으로 보여 준다. 처음 24개 뒤
더 보기로 확장하고 사진 본문은 표시할 때 읽는다. 공유 선택과 원문/AI 비교는 해당
작업을 열 때 보여 준다. 선택한 글 공유와 문서 전체 파일 다운로드의 범위를 설명한다.

## 기록을 연결해도 원문과 사진은 유지한다

연결 시 계획을 고르고, 활동을 선택하거나 계획에만 연결한다. 한 기록은 최대 한 계획,
선택적으로 한 활동에 연결된다. 다른 계획/활동으로 변경하거나 해제할 수 있다.
기록 ID·원문·사진·경험 날짜·recordedAt은 원자적 이동에서 유지한다.
계획 삭제는 기록을 독립 문서로 보존한다. 기록 자체 삭제는 별도 확인 행동이다.

파일은 outing 또는 memories다. outing에는 plan/originalPlan이 필수이고 memories에는
계획이 없다. 빈 일정 wrapper로 독립 기록을 흉내 내지 않는다. 문서 ID와 계획 ID가
다를 수 있다. 같은 ID의 다른 가져오기 내용은 복사본이 되며 기존 문서를 덮지 않는다.
구버전 파일은 거부하지만 기존 3.0 로컬 자료는 별도 변환해 보존한다.

## 혼자 또는 함께, 느슨하게 계획한다

혼자·함께는 선택이다. 지역, 대략적인 사용 시간, KRW 예산(전체 / 한 사람당), 가까운
이동, 한 곳만 방문을 저장하고 직접 계획과 AI 요청에 똑같이 사용한다. 빠른 조건은
가까운 곳 / 한두 시간(기본 120분) / 적게 쓰기(기본 10,000원) / 한 곳만이며 세부 편집할 수 있다.
혼자는 동행자와 합류 질문을 요구하지 않는다. 날짜·정확한 시각·마무리 시각도 선택이다.
활동 하나, 미정 시각, 자정 이후 마무리도 정상 계획이다. 확인하지 않은 가격·영업·이동
시간을 확정 정보로 표현하지 않는다. 최근 혼자 여가 관련 자료는 아이디어 배경이며
사용률이나 제품 수요의 실증으로 해석하지 않는다.

## 짧은 작업과 긴 AI 작업

장소 직접 변경, 기록 편집, 연결과 공유는 시트다. 완료/닫기 뒤 원래 화면의 초점과
스크롤을 복원한다. Escape/뒤로는 최상위 시트를 먼저 닫고 시트를 중첩하지 않는다.
긴 생성·재계획·기록 표현 요청과 검토는 전용 화면이며 입력·답안·화면 위치를 복원한다.
사용자 AI 앱의 대화 승인과 DatePack의 변경 검토 후 저장은 별도다.

작성 중 기록은 record-form:new/edit/legacy 기기 초안에 저장한다. 기존 3.0
memory:<documentId 또는 planId> 입력은 이어 쓰기로 접근하고, 의도적 저장과 초안 완료
표시를 함께 커밋한다. AI 답안은 memory-answer:<documentId>에 분리한다.
동시 편집으로 revision이 달라지면 입력을 유지한 채 최신 내용 비교와 명시적 재시도를 제공한다.
미저장 새 File은 같은 실행의 닫기·재시도에는 유지되지만 완전 종료 뒤 다시 선택해야 한다.

현재 장소는 수동 확인 또는 명시적 동의의 요청별 one-shot GPS로 다룬다. 정확 좌표는
휴대 파일·AI에 넣지 않는다. 공개 경로/resolver 서비스는 disabled이며, 지도 열기는 경로
검증이 아니다. 영향 없는 편집은 직접 저장할 수 있고, 이동 검증이 필요한 변경은
verified 근거 없이는 적용하지 않는다. 보호 조건과 오래된 AI 답안 차단을 유지한다.

## 확인한 범위와 후속

U01 저장/변환/파일 검사, U02 사진/연결/충돌 브라우저, U03 조건/전용 화면/실제 v3
초안 복원 증거 위에 U04 최종 빌드 통합 검증을 수행한다. 최신 결과는
[release readiness](release-readiness.md)와 [UI 기록](ui-audit.md)에 연결한다.
실제 iOS/Android 설치 PWA, GPS, 외부 AI 앱, OS 공유, HEIC 변환과 보조기술은
일반 브라우저·모의 검사로 완료했다고 주장하지 않는다. 모집·배포·게시·새 추천 서버,
계정·자동 위치 추적·가계부·추천 피드는 이번 범위가 아니다.
